# Notes

This archive has **no `manifest.json`**, as if someone zipped a folder by
hand. That is still a valid `.mdz` file.

The archive root holds two Markdown files, `notes.md` and `README.md`.
`README.md` is a support file, so it is set aside, which leaves `notes.md` as
the only candidate. If your app opened `README.md` instead, its entry point
discovery is wrong (Section 5.5, rule 3).
